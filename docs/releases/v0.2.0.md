# v0.2.0

- Add Routes navigation and idle/busy Worker observations, with grouped Queue progress counts. These features require Server 2.2 or later and observation-capable Workers.
- Add case-insensitive fuzzy Task name search through the Server.
- Add dismissible warnings when the connected Server is older than the installed Client.
- Change transient errors to corner notifications with duplicate suppression, dismissal and independent retry recovery.
- Fix status counts to preserve the applied name and filter when switching Task status.
- Fix Task drawer navigation, browser history and focus when switching between Tasks or interacting with notifications.
- Fix keyboard navigation and dismissal for dropdowns and saved-view menus, including WebKit.
- Fix selection preservation during sorting and saved-view comparison, Worker pagination recovery and long notification wrapping.

Validated against Labtasker 2.2.0 using both Client 2.1.0 and Client 2.2.0. No connection or saved-view migration is required.

Full Changelog: https://github.com/luocfprime/labtasker-webui/compare/v0.1.1...v0.2.0
